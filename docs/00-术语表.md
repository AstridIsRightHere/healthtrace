# 00 术语表

## 目标、产出与下一步

目标：让产品、技术与论文使用同一套词义。产出：本项目常用术语及容易混淆的边界。下一步：新术语首次出现时更新本表；具体技术方案以ADR和DEC为准。本稿为第二阶段补充评审稿。

| 术语 | 中文含义 | 康迹中的用途与边界 |
| --- | --- | --- |
| MVP | 最小可用产品 | 能完整解决核心场景并满足安全门槛的首版，不表示可省略权限与备份 |
| PRD | 产品需求文档 | 定义用户、范围、功能与非功能要求 |
| OCR | 光学字符识别 | 从照片识别文字/字段；输出草稿，须人工核对，不能当成诊断 |
| PWA | 渐进式Web应用 | 浏览器运行、可按平台能力添加到主屏；不承诺后台同步，医疗数据不离线缓存 |
| API / REST | 应用接口 / 一种资源接口设计风格 | 用HTTP方法及资源路径连接前后端；REST本身不保证安全 |
| HTTP / HTTPS | 超文本传输协议 / 受TLS保护的传输 | 状态码表达请求结果，HTTPS保护传输，不替代存储加密和权限 |
| TLS | 传输层安全协议 | 浏览器与服务端等网络链路加密与身份验证 |
| RPO | 恢复点目标 | 最多可容忍丢失的近期业务数据时间；建议24小时，尚待确认 |
| RTO | 恢复时间目标 | 从故障处置启动到安全重新开放的目标时长；建议8小时，尚待确认 |
| BCrypt | 带盐、自适应成本的密码散列算法 | 存密码验证结果，不是可解密加密；成本参数待评审 |
| JWT | JSON Web Token，一种令牌格式 | 签名不等于内容保密；不是所有系统必用，首版建议服务端会话 |
| 会话 / Cookie | 登录状态 / 浏览器保存并按规则发送的小段数据 | 会话可由Cookie承载标识；需HttpOnly、Secure等控制，并评估CSRF |
| CSRF | 跨站请求伪造 | 浏览器自动携带凭据时被诱导操作；不能仅靠隐藏按钮防范 |
| XSS | 跨站脚本攻击 | 不可信内容被当脚本执行；OCR文字也必须安全展示 |
| ADR | 架构决策记录 | 记录选型背景、理由、替代及后果；提议不等于已批准 |
| DEC | 本项目待决策条目编号 | 跟踪尚无结论的参数/供应商等；并非行业统一文档格式 |
| RTM | 需求追踪矩阵 | 将需求关联到设计、测试和证据；有映射不表示测试已通过 |
| FR | 功能需求编号 | 如FR-007逐项确认并正式保存 |
| NFR | 非功能需求编号 | 如权限、隐私、性能、恢复与可维护性 |
| TC | 测试用例编号 | 主验收及扩展用例；未执行不能写通过 |
| RISK | 风险编号 | 跟踪风险、措施、证据与剩余风险 |
| ER | 实体关系模型 | 描述账号、档案、报告、检测结果等实体关联 |
| 账号 / 患者档案 | 操作者身份 / 健康资料所属者 | 家属账号不是患者本人；关系画像不能自动授予权限 |
| 报告 / 检查项 / 指标 | 一份来源资料 / 具体检测结果 / 标准或临时定义 | 一报告多图多项，同一指标可多次测量，不任意去重 |
| 草稿 / 正式记录 | 未完成核对的数据 / 确认后的业务记录 | 只有正式结果入图，保留原图与原始OCR用于核对 |
| 可比组 | 可合理放在同组比较的结果 | 按指标、单位及已知方法标本区分，同名同单位不保证医学等价 |
| 列表移除 / 彻底删除 | 展示操作 / 数据生命周期处置 | 两者不同；移除后图表行为和期限由DEC-002确认 |
| 幂等 | 重复请求不造成重复业务副作用 | 网络重试不能生成多条正式记录；不代表每次响应都完全相同 |
| 摘要 / 加密 | 单向计算指纹 / 使用密钥保护可还原内容 | 图片摘要用于重复提示，不能替代原图加密；低熵信息摘要也可能泄露 |
| 合成 / 去标识 / 匿名化 | 自行虚构 / 减少直接标识 / 无法识别且不可复原 | 改名真实报告不等于合成；去标识数据仍可能是个人信息 |
| CI / CD | 持续集成 / 持续交付或持续部署 | 本项目建议自动检查与构建、人工批准生产发布，非自动直推main |
| E2E | 端到端测试 | 从界面覆盖少量关键旅程，不代替规则/权限/恢复测试 |
| Flyway / Liquibase | 数据库版本迁移工具 | 追踪结构变更历史；不自动解决所有数据回滚 |
| MyBatis | Java持久化映射框架 | 显式管理查询映射，便于学习SQL与权限过滤 |
| Pinia / Vuex | Vue状态管理方案 | 管理界面共享状态，不应持久保存健康资料或访问令牌 |
| ECharts / TypeScript | 图表库 / 带静态类型的JavaScript语言扩展 | 图表表达与契约检查工具；不代替医学语义或运行时校验 |
