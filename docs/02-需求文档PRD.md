# 02 需求文档 PRD

状态：第二阶段评审稿，尚未实现或测试。第一阶段范围已确认；2026-10-20 已确认 DEC-008/009/011/012/015/017/018，其他未决参数和方案仍以 DEC 台账为准。

## 目标、产出与下一步

目标：定义可追踪且可验收的MVP需求。产出：FR/NFR唯一编号及版本边界。下一步：与故事、设计、测试映射核对，再评审进入编码的条件。

## 背景、画像与场景

长期就医者面临报告散落、难比较前后指标、不了解就医频率与开药变化的问题。MVP先解决报告、指标和基础就医记录；药物数量变化需要后续结构化处方，不能声称首版已解决。

| 画像 | 目标 | 约束 |
| --- | --- | --- |
| 成年子女代管 | 帮父母整理复查结果，准备沟通 | 需患者授权；操作者不是数据主体 |
| 成年患者本人 | 找到历史报告，查看指标变化 | 不熟悉单位与术语；需可核对原图 |
| 配偶/其他成年代管 | 在授权范围内整理资料 | 关系画像只改变文案，不扩大权限 |

用户旅程：去医院前查看报告与趋势；就医后上传新报告、核对、关联就诊；空闲时管理关注项和查看长期变化。未成年人及无法自主授权患者不在首版服务范围。

### 指标与图表细则

血常规：白细胞计数WBC、红细胞计数RBC、血红蛋白HGB、血小板计数PLT、中性粒细胞百分比、淋巴细胞百分比、单核细胞百分比、红细胞压积HCT、平均红细胞体积MCV；肝功能：ALT、AST、总胆红素、直接胆红素、总蛋白、白蛋白；肾功能：肌酐、尿素氮、尿酸。默认关注WBC/HGB/PLT/ALT/AST/肌酐。别名、标准单位是设计值，需专业资料核对；标准单位不代表自动转换。

无数据为空状态；单点不产生趋势；缺失不插值，相邻点连线并提示“中间无数据”；Y轴自适应不裁剪极端点。阴性/阳性、`<某值`、`>某值`不作为精确值折线点。同日无法确定先后时不算当日结果之间增减，卡片显示“该日有多个结果，点击查看”；若前日也有多条歧义结果，则不擅自选基准。上升/下降不代表好/坏，不输出病情判断。

未知项保留原名称、值、单位、范围、报告和日期。临时指标仅患者档案范围有效、保留归并状态、展示参考提示，不参与跨用户统计。DEC-015（2026-10-20 已确认）规定：同名同单位同档案自动合并；别名不同但单位相同且同档案时给出强提示（判断依据与合并前后图表预览），由用户选择合并或暂不合并，合并后可一键撤销；同名不同单位不推荐换算、不自动合并，提示单位风险并提供原始报告和手动分开展示入口；跨档案永不合并。合并是临时指标身份整理，不推断医学等价，已知方法/标本差异仍分可比组。手动合并、分开及撤销均记录 AUDIT_EVENT，保留来源且不因归并删除原始结果。MVP 包含上述自动归并与系统提示后的确认/撤销、分开展示；v1.1 的完整手动归并工具不反向推迟这些 MVP 规则。

### 首页文字

本人展示“我的指标”；代管使用患者昵称，无昵称时“家人”。第一阶段已确认空状态：无数据卡片“暂无数据”；无关注指标“添加你关心的指标”；无报告“上传第一份报告”。搜索无结果显示“暂未提取到该指标”。

### NFR-006 可访问性与版本边界（DEC-018）

**MVP 可访问性基线**：

- WCAG 2.2 AA：文本对比度≥4.5:1；触控目标≥44×44 CSS px（项目采用的更严格触控基线，不将 44px 误述为 AA 本身的最低要求）；200% 缩放不失真、不丢失内容或操作；键盘可操作且焦点始终可见；已知信息自动填充，避免冗余输入；帮助入口位置一致。
- 深色模式跟随系统，设置可手动覆盖为“浅色 / 深色 / 跟随系统”；字号四档：小 14px、标准 16px（默认）、大 20px、特大 24px。
- 状态除红绿等颜色外，必须同时有文字、符号或线型；每个趋势图可切换结构化表格，包含日期、数值、单位、参考范围。
- 图表下方自动生成事实性文字描述，例如“过去 6 个月，血红蛋白从 112 g/L 下降到 96 g/L，最近 3 次均低于该报告参考范围”。仅在数据支持时生成，逐条使用各报告参考范围；不跨单位/可比组推断，不使用“好转”“恶化”等判断，数据不足时如实说明。
- 表单错误同时提供文字提示与 aria-live 播报；关键元素有可理解的朗读内容，启用 iOS VoiceOver / Android TalkBack 后仍能完成“上传报告 → 核对确认 → 查看趋势”核心流程。

**v1.1 完整可访问性 / 老年人模式**：简化分步（一次只问一件事）、关键数值 TTS 语音播报、可选 Web Speech API 语音输入、PDF/CSV 数据导出与就医前摘要、区分“本人使用”和“代管操作”的照顾者辅助引导、可选 WebAuthn 生物识别登录。语音与摘要仅呈现已确认事实，不提供医疗判断。

**v2 / 长期候选**：图表声音化（sonification）、多语言 / 方言支持。上述版本归属见 DEC-011 与 21；确认文档不代表实现或通过可访问性测试。

## 隐私与安全需求（独立）

医疗健康属于敏感个人信息。昵称不能使真实报告匿名化。家属授权声明记录授权主张，不等于已核实授权或可以替代患者所需同意。明确收集目的、必要性、权利渠道、第三方处理及保留时限；按适用情形落实单独同意和个人信息保护影响评估。

开发、CI、截图、公开Issue和论文仅用自造合成数据，不使用真实报告简单改名。境内部署/OCR不自动保证合规；合同、区域、子处理者、训练用途、留存、删除、个人主体可开通性均须核实。邮件只发验证/恢复用途，不含医疗内容；禁用打开/点击追踪。

PWA不离线缓存医疗数据；退出应清理页面状态，照片与API不进Service Worker持久缓存。拒绝OCR与撤回不能被设置为丧失所有手动记录功能的惩罚。恢复期间先隔离，落实删除账本，再开放访问。
