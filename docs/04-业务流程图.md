# 04 业务流程图

## 目标、产出与下一步

目标：明确成功、失败与人工确认边界。产出：报告闭环、就诊闭环和删除流程。下一步：逐节点与FR-004～017、接口与测试对应。状态：设计建议，未实现。

## 拍照上传到图表

```mermaid
flowchart TD
    A[拍照或相册 多图一报告] --> B{账号已验证且有档案权限}
    B -- 否 --> C[拒绝真实资料上传 提示验证]
    B -- 是 --> D[校验文件与容量]
    D --> E{完全相同图片}
    E -- 是 --> F[提示 用户决定继续或取消]
    F -- 取消 --> Z[结束]
    F -- 继续 --> G[保存原图与待处理报告]
    E -- 否 --> G
    G --> H{同意第三方OCR}
    H -- 否 --> I[手动录入草稿]
    H -- 是 --> J[创建可恢复OCR任务]
    J --> K{识别成功}
    K -- 否 --> L[保留原图和失败状态]
    L --> M{用户选择}
    M -- 重试 --> J
    M -- 手填 --> I
    M -- 稍后 --> N[待处理列表]
    K -- 是 --> O[保留原始文本与提取结果]
    O --> P[别名映射 未知项保留]
    P --> PM{临时指标名称单位及档案}
    PM -- 跨档案 --> PX[永不合并 仅保留本档结果]
    PM -- 同名同单位同档案 --> PA[自动合并临时指标身份 保留原始来源]
    PM -- 异名同单位同档案 --> PH[强提示 判断依据与合并前后图表预览]
    PH --> PC{用户选择}
    PC -- 合并 --> PU[合并后可一键撤销]
    PC -- 暂不合并 --> PS[保持分开]
    PM -- 同名不同单位 --> PD[不推荐换算 不自动合并 提示单位风险]
    PD --> PV[查看原始报告 或手动选择分开展示]
    PU --> PE[手动合并 分开及撤销记入 AUDIT_EVENT]
    PV --> PE
    PX --> Q[对照原图逐项确认值单位日期]
    PA --> Q
    PS --> Q
    PE --> Q
    I --> P
    Q --> R{确认完整且校验通过}
    R -- 否 --> Q
    R -- 是 --> S[事务保存正式记录]
    S --> T[分可比组查询]
    T --> U[图表与非精确结果列表]
    S --> V[后续修改 保留原始来源与变更]
    V --> T
```

临时指标节点依据 DEC-015（2026-10-20 已确认），标准字典命中项正常进入逐项确认；不匹配上述归并条件的未知项保留独立临时指标后进入确认。草稿中的合并前后图表仅作标明“预览”的模拟，不写入正式趋势；图示手动操作的审计随操作记录，不能让草稿绕过确认。合并临时指标身份不等于合并原始报告或证明医学等价；正式图表仍按单位及已知方法/标本分可比组，跨档案结果不纳入查询。MVP 包含自动归并、提示确认/暂不合并、一键撤销及分开展示；v1.1 再提供完整手动归并工具。

OCR自动提取不能跨过确认节点。数据库正式保存与对象存储不是跨系统原子事务：通过任务状态、幂等与补偿处理残留，设计见ADR-004。用户取消不应导致已上传对象无限期留存，待清理规则进入删除生命周期。

## 就医时间线与后续月历

```mermaid
flowchart TD
    A[打开时间线] --> B{已有记录}
    B -- 否 --> C[空状态 添加就诊]
    B -- 是 --> D[按就诊日期倒序]
    C --> E[填写就诊日期 医院 备注]
    D --> E
    E --> F[可选关联本档报告]
    F --> G[核对检查日期与就诊日期]
    G --> H[保存就诊记录]
    H --> I[更新首页最近1至3条]
    H --> J[按就诊记录统计次数]
    H --> K[v1.1 月历按日聚合]
    D --> L[打开就诊详情]
    L --> M[查关联报告与原图]
```

同一天可有多条就诊；如何避免误录重复由提示与用户确认处理，不能以“同一天只能一次”覆盖真实情况。医院名称不与患者病情共享到公开日志。

## 删除与恢复约束

```mermaid
flowchart TD
    A[选择删除操作] --> B{列表移除还是彻底删除}
    B -- 列表移除 --> C[解释保留范围 用户确认]
    C --> D[隐藏列表 不声称数据已清除]
    B -- 彻底删除 --> E[解释原图OCR指标审计内容影响]
    E --> F[立即阻断访问并记录最小删除账本]
    F --> G[清理活跃数据与第三方副本]
    G --> H[备份按批准周期到期清除]
    H --> I[反馈状态与时间]
    J[备份恢复] --> K[隔离环境]
    K --> L[重放删除账本]
    L --> M[核对无数据复活再开放]
```

列表移除是否同时退出图表是DEC-002的一部分；本稿建议移除仅隐藏报告列表、正式指标仍保留，必须在确认前清楚告知；彻底删除必须退出图表。建议不等于已批准。
