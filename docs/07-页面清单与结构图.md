# 07 页面清单与结构图

## 目标、产出与下一步

目标：温馨且能清楚核对数据，减少代管者认知负担。产出：页面职责、元素、导航和版本。下一步：先做低保真设计与任务走查，不编写页面代码。

## 交互与隐私原则

采用柔和背景、清晰卡片与留白，正文/图表保持对比度；红绿不作为唯一异常表达，同时用文字与符号。图表不使用疗效暗示。上传和保存后明确是“已上传/待确认/已确认”，避免将OCR成功误认正式保存。

关键按钮适合触控，缩放后不遮住值和单位；照片放大便于核对。不展示诊断建议或广告。移动浏览器可能中断上传，不承诺后台同步。退出和页面切换后不留下敏感缩略图缓存，通知/邮件不暴露病情。
