## 设计边界

人工撤回与字典/邀请维护在MVP为受控人工流程，不强制提供后台REST接口。患者接管、多档、协作与处方不列为MVP接口。

所有带ID的资源鉴权，不能仅在列表过滤；图片签名链接短期且不写入日志/公开页面；撤回/删除后签名链接的立即失效能力需验证，无法撤销的供应商URL不得与“立即阻断访问”承诺冲突，可优先服务端鉴权代理。邮箱令牌不放日志，统一恢复响应避免枚举。上传与确认幂等，修改带版本条件；限流与CSRF见ADR-007。GET不执行删除、验证激活或密码修改。

### 已确认认证参数（DEC-017，2026-10-20）

以下为 MVP 契约基线，尚未实现或测试：

- 开通和密码重置：密码最小长度 12 位，不强制复杂度；服务端采用 BCrypt cost 12。
- 邮箱验证 token 有效期 24 小时，密码重置 token 有效期 1 小时；仍遵守单次消耗及不写入日志的约束。
- 登录会话不活跃超时 30 分钟、绝对超时 8 小时；活动不能延长绝对期限。Session cookie 设置 HttpOnly + Secure + SameSite=Lax。
- 登录失败 5 次锁定 15 分钟；锁定与恢复响应仍避免泄露账号存在性。
- CSRF token 有效期 2 小时；改变状态的请求执行 CSRF 校验，过期后不能继续使用。

### 已确认上传边界（DEC-008，2026-10-20）

MVP 上传支持 JPEG、PNG、HEIC、PDF；单文件上限 25 MiB，单报告最多 20 个文件（图片+PDF 合计），单用户总容量初始 1 GiB。客户端压缩图片长边至 2048 px，存储原始文件+压缩预览图，不能以预览图替代原件。上表 `/photos` 为历史建议路径；纳入 PDF 后的资源命名、字段、页数、处理链路和配额计量细则在接口契约评审时确认，不将 PDF 排除出 MVP。

（2026-10-25 上传模块实现确认）MVP 实现契约：`POST /api/v1/patient-profiles/{profileId}/reports` 创建草稿报告（状态 UPLOADING）；`POST /api/v1/reports/{reportId}/photos` 单文件 multipart 上传，part `original` 必填、`preview` 可选（仅 JPEG/PNG），参数 `pageOrder`（1～20）与 `duplicateDecision=ASK|KEEP`（默认 ASK；同档 SHA-256 命中时返回 200 `DUPLICATE_SUSPECTED` 且不落盘，KEEP 重新提交）；`GET /api/v1/patient-profiles/{profileId}/reports?status=DRAFT` 列出待处理报告；`GET /api/v1/photos/{photoId}/access?variant=preview|original` 本地存储直接流式返回（no-store），对象存储返回 5 分钟签名 URL 的 302。文件类型以服务端魔数检测为准；未验证邮箱上传返回 403 HT-2003；越权与不存在统一 404 HT-3001。

## API错误响应规范（设计草案）

本节描述契约，不提供JSON代码或实现。错误响应使用统一逻辑结构；网关和应用尽量遵循相同约定，客户端仍须处理断网、非JSON网关故障和无响应。

| 字段 | 类型 | 含义与约束 |
| --- | --- | --- |
| code | 字符串，必填 | 稳定业务错误码，例如HT-1001；客户端依据它处理，不依赖文案判断 |
| message | 字符串，必填 | 可面向用户的中文说明，不含SQL、堆栈、邮箱、病历或凭据 |
| traceId | 字符串，必填 | 服务端生成的不透明关联号；只用于定位，不含资源标识或个人信息 |
| fieldErrors | 列表，可选 | 每项仅field字段名与reasonCode、message；不回显输入值；非字段错误省略 |
| retryable | 布尔，必填 | 是否允许稍后重试的建议；写操作仍须幂等，不代表可无限重试 |

HTTP状态与业务错误码共同判定，不能所有错误都返回200。响应不携带原始请求、OCR内容或签名图片URL；错误响应及敏感成功响应不持久缓存。

### 错误码分段

| 分段 | 范围 | 初始建议码与语义 |
| --- | --- | --- |
| 通用请求 | HT-1000～1999 | HT-1001字段校验失败；HT-1002请求格式无效；HT-1003文件过大；HT-1004文件类型不支持 |
| 认证授权 | HT-2000～2999 | HT-2001未登录/会话失效；HT-2002账号或密码不匹配；HT-2003邮箱未验证；HT-2004当前操作禁止；HT-2005 CSRF校验失败；HT-2006凭据失效或无效 |
| 资源与版本 | HT-3000～3999 | HT-3001资源不可用；HT-3002版本冲突；HT-3003已达MVP档案限制 |
| 报告与指标 | HT-4000～4999 | HT-4001尚有未确认字段；HT-4002当前状态不允许操作；HT-4003缺少当前OCR同意；HT-4004缺少可比组选择；HT-4005单报告文件数已达上限（20）；HT-4006账号存储容量已满（1 GiB）（2026-10-25 上传模块补充） |
| 外部服务与配额 | HT-5000～5999 | HT-5001请求过频；HT-5002 OCR暂不可用；HT-5003邮件暂不可用；HT-5004存储暂不可用 |
| 内部故障 | HT-9000～9999 | HT-9001内部处理失败；外部只给安全说明与traceId |

码一经发布不重用其含义。重复图片是用户决策提示，按FR-005返回可继续的业务结果，不强行视为错误。查询无数据返回成功空列表，不报资源不存在。没有可比历史时返回成功与空态原因，不当成系统故障。

### HTTP状态码约定

| 状态 | 用途 |
| --- | --- |
| 200 / 201 / 204 | 查询/更新成功、资源创建、无响应体成功；204不附错误结构 |
| 202 | OCR/删除等任务已受理，返回任务资源；不等于已经处理完成 |
| 400 | 请求格式/字段无效、凭据无效或过期；不提供令牌有效性细节 |
| 401 | 缺失或失效登录身份、登录凭据不匹配；不泄露哪个字段正确 |
| 403 | 已认证用户邮箱未验证、缺少同意、CSRF或当前操作权限不足 |
| 404 | 资源不存在；跨账号/已彻删资源对外统一资源不可用，避免枚举 |
| 409 | 并发版本冲突、状态冲突、MVP档案限制、仍有未确认项 |
| 413 / 415 | 内容过大 / 文件媒体类型不支持 |
| 429 | 频率限制；可提供不含隐私的Retry-After提示 |
| 500 | 内部未预期故障，记录脱敏错误类别 |
| 503 | 依赖暂不可用或维护；不把供应商原始报错转发客户端 |

恢复密码请求在形式有效时，无论邮箱不存在、未验证或符合发送条件，均给统一受理说明（建议202），只有符合资格才发邮件；不通过状态码/文案泄露账号存在性，发送失败在受控运维记录处理。验证/恢复令牌消耗失败统一无效或过期说明。OCR任务受理后的失败由任务状态返回，任务查询本身成功仍为200；不能用查询的500假装任务失败。
