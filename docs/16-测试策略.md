# 16 测试策略

## 目标

验证 HealthTrace 在合成数据条件下的需求覆盖、隐私隔离、数据可信性及可恢复性，建立真实数据试用前的 P0 门禁。本文件是测试计划，不是已执行报告，没有真实病历实测、OCR 准确率结果或性能达标结论。

## 产出

产出测试分层、主验收目录、风险扩展用例、测试数据规则和发布判定。编号与 [15-需求追踪矩阵RTM](15-需求追踪矩阵RTM.md) 一致：TC-001 至 TC-018 对应 FR 同号，TC-101 至 TC-112 对应 NFR 同号，TC-2xx 为补充。下列用例状态全部为“未执行”。

## 范围与环境

基线为 Vue PWA、Spring Boot、MySQL，单体部署，成年本人或授权子女、配偶管理成年患者档案，MVP 一账号一个患者、模型支持多档案。测试应覆盖浏览器界面、服务端权限、数据及对象关联、OCR/邮件外部依赖失败、PWA 缓存与恢复。

开发与验证准备仅使用合成数据：虚构患者、医院、就诊与检验图像，标注“合成”，不得混入真实姓名、手机号、身份证、病历或未脱敏截图。至少准备互不授权的两个账号及管理员账号以验证隔离；增加未验证、已验证、撤回、注销状态。外部 OCR 仅在供应商门禁允许后使用合成样本，服务真实效果不能由模拟结果推断。

按 DEC-009 执行性能基准：首屏≤2s（4G中端手机），API平均≤500ms（家庭网络单用户），OCR草稿≤30s（正常网络单页图片），图表≤1s（单指标100点），列表≤1s（100条）。每项记录设备/浏览器、网络条件、数据集、请求或任务次数、原始时间戳与统计方法；未达到或未执行不得填为通过。至少考虑小屏手机、主流移动浏览器与桌面浏览器、弱网、断网和重连。先证明 2–3 位家人的目标规模可用，不把该规模外推成高并发能力。PWA 离线界面不得因缓存保留导致退出后仍能读取病历。

## 测试分层与重点

- 规则级：指标映射、可比性分组、逐项确认、参考范围与增减算法边界、就诊计数。
- 集成级：多图对象与报告关联、数据库与对象一致性、OCR 状态迁移、邮件验证及密码恢复、审计和删除。
- 端到端：邀请注册到录入确认、首页和趋势回顾、待处理恢复、授权撤回、彻删及注销。
- 安全与恢复：跨账号访问、管理员访问、缓存退出、密钥与日志、备份恢复及删除账本重放。
- 人工可用性：合成数据任务脚本，观察 2–3 位家人的完成情况、误解及恢复路径；只记录实际观察，不预填满意度。

验证优先级按风险排列，P0 包含权限隔离、未验证真实数据门禁、授权和必要同意、明文密码与密钥泄漏、草稿进入正式图表、删除后恢复复活等。P0 不可因工期或预算降级；一般展示问题可在明确影响与处置记录后排期。

## 工具建议与分层边界

单元测试：后端JUnit与必要mock，前端Vitest及组件测试候选；验证纯规则、输入边界、空值和状态转换，不访问网络或真实患者数据。集成测试：Spring Boot测试与MockMvc/真实MySQL测试实例候选，验证事务、查询、鉴权、幂等；对象存储、OCR和邮件用可控替身模拟超时/失败，并保留少量仅合成数据的供应商契约测试。避免只用内存数据库通过却未验证MySQL行为。

E2E：Playwright候选覆盖少量关键用户旅程，不重复穷举所有算法组合；移动浏览器仿真不能替代 iOS Safari/Android Chrome 实际验证。TC-106 必须使用真机 iOS Safari + VoiceOver、Android Chrome + TalkBack，逐一走上传→核对→趋势核心流程，检查焦点顺序/可见焦点、控件名称与状态、错误文本及 aria-live、200%缩放、非颜色编码、44×44 CSS px触控目标、主题/字号切换、趋势图结构化表格切换和客观文字描述边界；记录机型、系统、浏览器、辅助技术版本与脱敏证据。权限安全测试须直接请求接口，不能仅凭按钮隐藏证明安全。恢复与供应商合同审查属于独立验收，不由UI自动测试代替。

工具均以开源能力为候选，精确版本及CI资源待DEC-012/004；本阶段不安装、不创建测试代码、不执行产品测试。没有为了覆盖率数字而写镜像实现的测试。

## 功能主验收目录

每条状态均为 **未执行**。

- **TC-001 / FR-001**：检查有效、无效、失效邀请码及验证状态；未验证能登录，不能上传真实病历、不能找回密码。预期门禁由服务端执行，不能只依赖界面隐藏。
- **TC-002 / FR-002**：检查正确和错误登录、BCrypt 密码保存、验证前后恢复流程及过期恢复凭据；预期无明文密码、无账号枚举性提示或可复用恢复凭据。
- **TC-003 / FR-003**：本人及授权子女、配偶分别建立档案，检查成年声明、授权声明与时间戳；预期 MVP 不越过一账号一患者，未来模型扩展不导致跨档案读取。
- **TC-004 / FR-004**：多图构成同一报告、历史补录与部分上传中断；预期页序与报告关联正确，报告日期不被上传时间覆盖。
- **TC-005 / FR-005**：同图重传、同报告不同图片及外观近似但不同报告；预期只有完全相同图片触发此重复提示；不同照片不自动合并或删除，用户可继续或取消。
- **TC-006 / FR-006**：同意 OCR、拒绝并手填、超时失败、异常回调；预期只产生草稿或待处理，失败可见且无正式图表污染。
- **TC-007 / FR-007**：逐项确认、存在未确认项、重复保存及网络中断；预期只有符合确认规则的正式数据入图，原图及 OCR 保留且不重复创建正式记录。
- **TC-008 / FR-008**：逐项检查 WBC、RBC、HGB、PLT、中性粒细胞百分比、淋巴细胞百分比、单核细胞百分比、HCT、MCV、ALT、AST、总胆红素、直接胆红素、总蛋白、白蛋白、肌酐、尿素氮、尿酸；预期映射准确，歧义交由用户确认。
- **TC-009 / FR-009**：搜索标准及临时指标、未知项确认创建、同档案同名同单位自动合并、异名同单位展示依据及前后预览并由用户选择合并/暂不合并、撤销与分开展示、同名不同单位不换算且不自动合并、跨档案永不合并（自动合并仅作用于同一档案内重复指标/别名指向，不合并报告或检验记录）；预期手动合并分开写入 AUDIT_EVENT，排序刷新后保留。
- **TC-010 / FR-010**：单位、方法、标本差异，真实日期间距，7 天/30 天/1 年/5 年/自选，单点、缺失、区间及阴阳结果；预期不可比分组不连线、不换算，缺失不插值，非精确数值只列表。按 DEC-018，为每种趋势视图验证图表/含日期、数值、单位、参考范围的结构化表格可切换；客观文字描述不得对不可比组造趋势或作好转/恶化判断。
- **TC-011 / FR-011**：不同报告参考范围变化、前值为零、同日多次结果存在歧义；预期参考范围按条，前零不算百分比，同日歧义不算增减，不跨不可比分组计算。
- **TC-012 / FR-012**：空首页及有记录首页；预期昵称、六关注 WBC/HGB/PLT/ALT/AST/肌酐、排序、待处理、最近 1–3 次就诊和上传入口正确。
- **TC-013 / FR-013**：一次就诊多份报告、历史就诊、编辑医院及备注；预期按就诊实体计数、日期排序，关联报告增加不使就诊数增加。
- **TC-014 / FR-014**：正式数据修改及回看；预期前后值、操作者、时间与依据留审计，原图和 OCR 不被无声覆盖，图表反映正式新值。
- **TC-015 / FR-015**：上传或 OCR 中断、失败重试、重复回调及恢复；预期待处理可发现、状态可解释、恢复不重复入库。
- **TC-016 / FR-016**：分别执行列表移除与彻底删除；预期说明及后果不同，彻删立即禁访问、关联衍生物清理且恢复后不复活。24 小时活跃清除、30 天备份到期仅作 DEC-002 草案参数验证。
- **TC-017 / FR-017**：人工撤回及注销的申请、核验、执行、通知和留证；预期相关访问终止并进入删除流程。自助撤回及接管不计入 MVP，通过 v1.1 用例另行验证。
- **TC-018 / FR-018**：管理员管理邀请和字典，再尝试读取病历、原图、OCR 与图表；预期仅管理职责被允许，病历内容默认拒绝。

## 非功能主验收目录

每条状态均为 **未执行**。

- **TC-101 / NFR-001**：跨账号猜测标识、访问对象链接、草稿及任务，切换账号后读缓存；预期所有内容入口均校验患者归属，管理员不能越权。
- **TC-102 / NFR-002**：审查境内 OCR 合同、不训练、留存和删除证据，测试同意与拒绝路径；预期未完成必要同意不发往 OCR，拒绝仍可手填。
- **TC-103 / NFR-003**：检查传输、备份及敏感存储保护、BCrypt、密钥独立与恢复；预期日志和备份不暴露可直接使用的密钥，授权恢复流程可用。
- **TC-104 / NFR-004**：模拟超时、任务中断、重复提交和回调；预期有界重试、错误可见、正式保存幂等。
- **TC-105 / NFR-005**：在 DEC-009 已确认条件下测首屏（4G中端手机）、API平均响应（家庭网络单用户）、OCR单页草稿（正常网络）、单指标100点图表、100条列表；分别判定≤2s、≤500ms、≤30s、≤1s、≤1s。记录原始时间戳、样本量及统计方法，未测量不得通过。
- **TC-106 / NFR-006**：在 iOS Safari+VoiceOver、Android Chrome+TalkBack 真机完成上传→核对→趋势，另测小屏与触控、错误文本/aria-live、200%缩放、焦点、非颜色编码、主题/字号、趋势结构化表格与客观描述边界；预期文本对比度≥4.5:1、触控目标≥44×44 CSS px（项目基线）、关键信息可读、错误可恢复且缓存不泄漏病历。记录机型/系统/浏览器/辅助技术版本和脱敏证据，未执行仍为未执行。
- **TC-107 / NFR-007**：按隔离恢复流程演练数据库、对象、密钥、删除账本；记录可恢复点及开放时间，按 DEC-003 批准参数判定，草案为 RPO 24 小时、RTO 8 小时。
- **TC-108 / NFR-008**：依据运维文档人工演练发布、配置核验与回退；预期不依赖未记录个人知识，版本及数据兼容风险清楚。
- **TC-109 / NFR-009**：核对服务器、域名、OCR、邮件、存储、异地备份及必要其他费用；预期年度估算完整，500 元上限目标若不成立则调整范围，不牺牲 P0。
- **TC-110 / NFR-010**：查审计完整性和运维日志脱敏；预期操作可关联、受限审计不含不必要正文，密码、凭据、密钥不入日志。
- **TC-111 / NFR-011**：检查活跃副本、缓存、对象、OCR 衍生物、供应商及备份到期，旧备份恢复；预期删除期限可证明、超时可发现、删除账本重放前不开服务。
- **TC-112 / NFR-012**：审查真实数据前法律评估及备案适用性核实记录；预期上线门禁明确，不把家属声明当作一切义务的替代。

## 风险扩展用例

每条状态均为 **未执行**。

- **TC-201**：草稿混有确认及未确认项时，绕过前端直接提交；覆盖 FR-007、NFR-001，验证服务端确认规则。
- **TC-202**：同日两个不同医院、不同方法结果及零前值；覆盖 FR-010、FR-011，验证不产生误导增减。
- **TC-203**：彻删后恢复删除前备份；覆盖 FR-016、NFR-007、NFR-011，验证账本补齐、重放及禁访问门禁。
- **TC-204**：数据库有记录而对象缺失、对象有文件而无正式关联；覆盖 FR-004、FR-015、NFR-007，验证一致性检查和隔离处理。
- **TC-205**：拒绝 OCR、供应商停用与邮件不可用；覆盖 FR-001、FR-002、FR-006、NFR-002，验证手填与可解释恢复，不绕过验证门禁。
- **TC-206**：撤回或注销时存在任务及重复回调；覆盖 FR-015、FR-017、NFR-011，验证任务停止及衍生数据不能重新生成。
- **TC-207**：退出、账号切换、PWA 更新与离线重开；覆盖 NFR-001、NFR-006，验证浏览器缓存及本地状态的清理边界。

## 执行证据与发布判定

每次执行记录需求版本、用例编号、环境、合成样本、步骤说明、预期、实际、时间、执行者、证据、缺陷及复验结果。截图同样只可使用合成数据。失败不可改成“暂时通过”，未执行不得算完成覆盖。

允许进入真实数据试用的必要条件：所有 P0 主验收与相关扩展用例通过；权限、同意、供应商、邮件验证、删除和隔离恢复证据完整；必要法律评估及备案适用性已核实；DEC 中影响上线的参数已确认。当前均无通过证据，不应据此宣布可上线。

测试停止条件包括发现跨账号读取、管理员默认可读病历、未验证真实上传、草稿误入图表、删除后复活、密钥泄漏。应立即停止相关验证并保全合成证据，修复后复验受影响链路。
