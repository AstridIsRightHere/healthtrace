## 3. 追踪口径

FR-001 至 FR-018 依次为：邀请验证、登录恢复、档案授权、上传、重复、OCR 草稿手填、确认、字典、搜索临时关注、图表比较、范围增减、首页、时间线、修改审计、待处理、删除、注销撤回、管理。

NFR-001 至 NFR-012 依次为：隔离、隐私、加密、任务可靠、性能、易用、恢复、工程、预算、日志、删除、法律。功能验收 TC-001–TC-018 与 FR 同序；非功能验收 TC-101–TC-112 与 NFR 同序。

ADR-001 至 ADR-008 依次为：PWA、单体、MySQL、OCR 人工确认、指标分组、数据生命周期、会话及加密、交付与许可。新增ADR-009～014依次为：Flyway迁移、Pinia状态管理、CI/CD、MyBatis、ECharts、TypeScript，均为提议。ADR记录选择及理由，DEC-001～025记录未决问题；出现关联不表示决策已完成。

确认者：项目发起人。依据：2026-10-20 对第二批四项 DEC 的明确决定；以下为范围、规则与验收目标的文档基线，未执行实现或产品测试。采用本批明确指定方案以消除范围与验收歧义，不虚构其他方案的实验淘汰或性能证据。

#### DEC-009 性能评测阈值（已确认，确认日期：2026-10-20）

- 首屏加载≤2 秒（4G 网络、中端手机）。
- API 平均响应≤500ms（家庭网络、单用户）。
- OCR 草稿返回≤30 秒（正常网络、单页图片）。
- 图表渲染≤1 秒（单指标 100 个数据点）。
- 列表页渲染≤1 秒（100 条记录）。

影响 MVP 的 NFR-005/TC-105，同步 02/09/16；替代此前“性能阈值待定”。此处仅确认耗时阈值，OCR 准确率/低置信度、评测样本、设备和网络实测配置、计时及重复测量方案仍须细化记录；PDF/多页不套用单页图片耗时结论，可靠性重试参数不因本项自动确认。

#### DEC-011 版本归属汇总（已确认，确认日期：2026-10-20）

- **MVP（核心闭环必需）**：邀请注册+邮箱验证、单患者档案、图片+PDF 上传、OCR 草稿+手填、逐项确认、18 项字典+临时指标关注、分单位分可比组图表、基础就诊时间线、修改留痕、列表移除+彻底删除、注销+人工撤回渠道。
- **v1.1（体验增强）**：多档案切换、患者接管、自助撤回授权、邮箱变更、PDF 批量上传、月历视图、临时指标手动归并、疾病/检查手填、匿名计数（候选）、完整老年人模式、关键数值语音播报、数据导出与就医摘要。
- **v2（高风险/高成本）**：多人协作、处方/药物/数量、自动单位换算、自建 OCR。

完整总表同步 21 的显眼位置；将疾病/检查与处方/药物/数量的历史建议确立为版本归属。MVP 仍有 DEC-015 的自动归并及系统提示交互，v1.1 是完整手动归并工具；匿名计数仅候选且默认关闭，DEC-013/014 等独立依赖不解除。版本归属不代表工期承诺或完成验证。

#### DEC-015 临时指标可比性（改进版，已确认，确认日期：2026-10-20）

1. 同名同单位同档案：自动合并。
2. 别名不同、单位相同、同档案：系统给强提示，包含判断依据与合并前后图表预览；用户选择合并或暂不合并；合并后可一键撤销。
3. 同名不同单位：不推荐换算、不自动合并；提示单位不同的风险，提供“查看原始报告”和“手动选择分开展示”入口。
4. 跨档案：永不合并。
5. 用户手动合并/分开操作记录在 AUDIT_EVENT 中，撤销同样留痕。

影响 MVP 的 FR-009/010/011，同步 02/04/19 及设计/验收追踪。合并为指标身份归并，不合并患者、报告或覆盖原始结果；仍按单位和已知方法/标本分可比组，不能由名称与单位推断医学等价。不采用跨档归并和自动换算，以保持隔离与来源可追溯；具体撤销关联、并发和物理模型仍须设计。

#### DEC-018 可访问性基线（扩充版，已确认，确认日期：2026-10-20）

**MVP 可访问性基线**：

- WCAG 2.2 AA：文本对比度≥4.5:1、触控目标≥44×44 CSS px、支持 200% 缩放不失真、焦点始终可见、自动填充已知信息以避免冗余输入、帮助入口位置一致。其中 44×44 CSS px 是项目更严格的触控基线，不误述为 WCAG AA 自身的最低尺寸。
- 深色模式：跟随系统，设置允许手动覆盖为浅色 / 深色 / 跟随系统。
- 字号四档：小 14px / 标准 16px（默认）/ 大 20px / 特大 24px。
- 非颜色编码：红绿之外同时用文字、符号或线型表达状态。
- 每个趋势图可切换结构化表格，列出日期、数值、单位、参考范围。

- VoiceOver / TalkBack 兼容：关键元素朗读可理解，开启辅助工具后可完成“上传报告 → 核对确认 → 查看趋势”核心流程。
