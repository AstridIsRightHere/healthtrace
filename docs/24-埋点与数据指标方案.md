# 24 埋点与数据指标方案

> 设计阶段方案。MVP 默认只保留必要安全与运行日志，不启用第三方分析，不默认采集产品行为埋点。文中运营计数是受限的方案候选，不代表已经部署或获得同意。

## 1. 目的与收集边界

必要日志仅用于发现越权与认证异常、定位任务失败、验证备份恢复和执行删除流程，不用于疾病推断、用户画像营销或训练。健康报告原图、正式数据和 OCR 审计属于业务数据，应由业务权限及生命周期保护，不能复制到运行日志或分析平台。

MVP 不记录检查数值、指标名称、报告及就诊日期、图片、邮箱全文、报告全文、OCR 全文、密码、验证码、令牌、授权声明全文或请求正文。日志事件本身的服务器时间仅用于运行定位，不代表允许记录患者检查日期。禁止用自由文本错误信息、URL 参数、文件名或异常堆栈夹带上述内容。

IP、设备信息、账号标识及关联编号可能属于个人信息；仅在必要性成立且有访问、留存依据时使用。随机标识、去标识和聚合并不必然使数据匿名。

## 2. 数据分层

| 层次 | 内容与用途 | 默认边界 |
| --- | --- | --- |
| 业务数据 | 档案、报告原图、OCR 草稿、确认结果、授权时间戳 | 仅本人或经授权账号可访问；管理员默认不能查看健康内容 |
| 业务审计 | OCR 处理与逐项确认、修改、删除及撤回的可追溯记录 | 受业务权限保护；必要内容按生命周期保留，不当作统计明细外发 |
| 安全日志 | 认证结果、验证限制命中、权限拒绝、必要管理操作 | 只用事件类型、结果类别及最小必要关联标识；记录不含健康内容 |
| 运行日志 | 任务状态、脱敏错误类别、耗时、恢复与删除任务执行结果 | 禁止输出载荷、OCR 文本和用户文件名；运维仅获最低必要权限 |
| 产品分析 | 页面访问、点击、漏斗、匿名计数 | MVP 默认不启用；v1.1 仅候选，DEC-014 未确认不得收集 |

## 3. 必要事件候选字典

以下为待评审事件，不是配置模板。具体字段、留存和权限须在编码前按最小化原则确认。

| 事件 | 最小信息候选 | 目的 | 不得携带 |
| --- | --- | --- | --- |
| 认证尝试 | 运行时间、成功或失败类别、必要请求关联号 | 发现异常与恢复故障 | 邮箱全文、密码、验证码及认证凭据 |
| 验证限制命中 | 限制类别、拒绝结果 | 证明未验证账号不能真实上传或找回 | 上传内容、邮箱、输入正文 |
| 权限拒绝 | 操作类别、拒绝结果、受限关联号 | 检查跨账号隔离与错误授权 | 目标患者信息、资源内容 |
| 报告处理任务 | 随机任务关联号、状态转换、耗时、错误类别 | 定位 OCR 与处理失败、重试问题 | 图片、文件名、OCR 内容、指标名或数值 |
| 删除处理任务 | 随机任务关联号、移除或彻删类别、阶段与结果 | 核查生命周期执行 | 报告内容、检查日期和患者身份 |
| 备份恢复任务 | 演练编号、开始结束时间、校验结论、失败类别 | 验证恢复能力 | 备份正文、存储凭据、健康内容 |
| 管理操作 | 最小操作人关联号、操作类别、结果 | 追踪必要运维行为 | 被管理账号邮箱、健康内容或秘密 |

错误说明优先使用预先定义的类别，确需诊断细节时先在合成数据环境复现。日志访问要鉴权、审计且与患者内容访问分离，不通过扩大管理员健康数据权限排障。

## 4. 运行指标候选与计算口径

仅使用已获准的必要运行日志形成受限统计，不新增患者行为追踪。建议以周为观察窗，低样本量时只作内部故障定位，不公开细粒度分组。

| 指标 | 分子与分母或口径 | 解释限制 |
| --- | --- | --- |
| 报告处理任务完成率 | 窗口内创建任务中在观察截止前完成的数量／创建数量 | 同列待处理、失败、取消数量；未完成任务不直接认定失败，需写明观察截止 |
| 处理耗时 | 从任务受理到草稿可用的时长分布 | 区分排队、处理、超时；失败单独报告，不包含人工确认时长 |
| 任务重试恢复率 | 重试后完成的任务数／发生重试的任务数 | 使用任务关联号去重，不以重试次数充当任务数 |
| 权限拒绝次数 | 按粗粒度操作类别统计拒绝事件 | 不能据此认定攻击者或患者行为，不公开小样本用户分组 |
| 删除任务完成情况 | 分别统计移除、彻删申请的完成、处理中与失败数量 | 完成需满足约定范围；不能把列表不可见当成彻底删除 |
| 恢复演练结果 | 演练是否完成、观测 RPO 与 RTO、校验结论 | DEC-003 建议 RPO 24 小时、RTO 8 小时，待确认；未测不能宣称达标 |
| 基础服务可用情况 | 经确认探测周期内成功次数／有效探测次数 | 采样口径仍需定义；DEC-009 已确认产品性能阈值：首屏≤2s（4G中端手机）、API平均≤500ms（家庭网络单用户）、OCR草稿≤30s（正常网络单页图片）、单指标100点图表≤1s、100条记录列表≤1s；不等于用户端端到端可用率 |

不采集真实用户指标确认率、疾病分布、检查频次、指标异常率或“健康改善率”。OCR 评测应先以自造合成样本评估字段识别与错误类型，明确样本规模和构造偏差；不能把合成样本结果写成真实临床报告准确率，也不能代替逐项确认。

## 5. 留存、删除与供应商

运行日志的具体留存天数、权限名单及导出范围待确认，不沿用备份建议的 30 天自动推断日志期限。日志与备份分别定义生命周期；彻删申请需要说明在线副本、对象存储、OCR 供应商、业务审计和备份如何处理。恢复时应重新执行已生效的删除与授权撤回，防止被恢复数据重新进入可用状态。

境内 OCR、存储与邮件供应商应确认受托处理边界、合同、不用于训练、留存与删除；必要时需最小化关联信息。供应商自带分析功能不得因默认设置而悄然开启。真实数据上线前完成告知、同意和适用备案评估。

## 6. v1.1 匿名计数候选

仅当有明确产品问题且必要日志无法回答时，评估少量粗粒度计数。必须先确认目的、必要性、法律基础、字段、同意或其他适用依据、退出方式、留存、重识别风险、外部处理方及低样本处理。评估不通过就不启用；不能以“没有邮箱”或“只有计数”宣称绝对匿名。

## 7. 验收与追踪

NFR-002 隐私、NFR-010 日志对应 TC-102、TC-110，应以合成报告检查日志没有敏感字段，并覆盖异常堆栈、上传失败、OCR 失败、验证限制及删除失败。NFR-004、NFR-005、NFR-007、NFR-011 对应 TC-104、TC-105、TC-107、TC-111；DEC-009 的性能阈值已确认但尚未测量，准确率、低置信阈值和样本方法仍待细化，均不得提前判定通过。

## 8. 待确认事项、目标产出与下一步

| 待确认事项 | 目标产出 | 下一步 |
| --- | --- | --- |
| 必要日志字段、留存、权限与脱敏 | 可审查的最小字段字典及删除安排 | 项目发起人在编码前核实，优先删去无用途字段 |
| DEC-003、DEC-009 | DEC-003 恢复参数及 DEC-009 性能阈值的测量证据；准确率、低置信阈值和样本方法仍待细化 | 性能按已确认条件定义样本、窗口与验证方式后验收，准确率相关口径确认前不写结论 |
| DEC-005、DEC-006、DEC-007 | 供应商和境内上线所需证据 | 真实数据上线前确认合同、同意与备案 |
| DEC-014 匿名计数 | 启用或放弃的书面结论 | v1.1 编码前评估，MVP 保持默认不采集 |
