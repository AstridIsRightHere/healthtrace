## 4 别名归并说明

**归并原则（按优先级）：**

1. **代码相同才可归并。** 同一 8 位代码的不同写法（全称、简称、英文缩写）视为同一指标。
2. **代码不同，即使中文近似，也绝不归并。** 典型：`NEUT%`（百分比）与 `NEUT#`（绝对值）、`RET`（绝对计数）与 `RET%`（百分比）、`eGFR` 与 `Ccr`。
3. **无国标代码项不向有代码项归并。** 例如 `间接胆红素` 无代码，不得并入 `总胆红素 1700504A`。
4. **同名不同义必须拆分。** `PCT` = 血小板压积（无国标代码）或降钙素原（`1101504A`），按**单位量纲 + 上下文 + 原文项目名**判别；判定失败时进入“待确认”而非猜测。
5. **标准名优先。** 展示层默认使用 §2、§3 的“标准项目名”，别名仅用于检索与 OCR 匹配。

**具体归并/不归并裁决表：**

| 情形 | 裁决 | 依据 |
| --- | --- | --- |
| `HGB` / `Hb` / `血色素` / `血红蛋白` → 血红蛋白测定 `0100401A` | **归并** | 同一代码 |
| `HCT` / `红细胞压积` / `PCV` → 血细胞比容测定 `0100501A` | **归并** | 同一代码；压积为旧称 |
| `ALT` / `GPT` / `谷丙转氨酶` → 丙氨酸氨基转移酶测定 `1500104A` | **归并** | 同一代码 |
| `AST` / `GOT` / `谷草转氨酶` / `天冬氨酸氨基转移酶` → 天门冬氨酸氨基转移酶测定 `1500204A` | **归并** | 同一代码；“天冬”为“天门冬”的省略写法 |
| `GGT` / `γ-GT` / `谷氨酰转肽酶` → γ-谷氨酰基转移酶测定 `1500904A` | **归并** | 同一代码 |

## 5 单位说明

**重要事实：WS/T 886—2026 只规定名称与代码，不规定单位。** 标准中的“标度”字段仅区分定量（A）、定性（B）、定名（C）、定序（D），不提供计量单位。因此：

- 单位来源分两类：`[权威:WS/T 404.1-2012]`（仅 ALT、AST、ALP、GGT 为 U/L）与 `[用户表]`（其余 43 项）。
- 系统**不做任何自动单位换算**；单位不同即视为不可比，图表自动分组。
- 单位变体仅作**识别**用途，不参与计算：

| 指标族 | 标准单位 | 常见变体 | 关系（仅供识别，不执行换算） |
| --- | --- | --- | --- |
| 细胞计数 | ×10⁹/L、×10¹²/L | `10⁹/L`、`/L`、`×10³/μL`、`K/μL` | 数值写法差异 |
| 血红蛋白 | g/L | g/dL、g/100mL | 相差 10 倍 |
| 肌酐 | μmol/L | mg/dL | 相差约 88.4 倍 |
| 尿素 | mmol/L | mg/dL（以氮计） | 换算依赖“尿素/尿素氮”口径，**禁止自动换算** |
| 尿酸 | μmol/L | mg/dL | 相差约 59.5 倍 |
| 酶类 | U/L | IU/L、μkat/L | IU/L 等价；μkat/L 为另一量纲 |
| 百分比类 | % | 小数（0.40 表示 40%） | 需人工确认后再分组 |

**单位缺失处理：** 报告未标单位时不猜测、不继承上次单位，标为“单位缺失”，该点不进趋势线，仅在时间线中保留原文。

## 6 参考区间处理原则

1. **字典不存储参考区间。** 结构上只存在 `OBSERVATION.reference_text / reference_low / reference_high` 三个字段，逐条记录**该份报告自己印的**参考范围（DEC-001）。
2. **参考区间天然带方法学与人群属性。** WS/T 404.1—2012 已直接证实：ALT、AST 因试剂是否含 5′-磷酸吡哆醛而有两套区间；ALP 因性别 + 年龄（20~49 岁 / 50~79 岁）分组；且标准明确“临床实验室应首选本文件的参考区间”，但使用前须验证。
3. **本字典中出现的区间数值仅作“提示文案”依据**（例如“该指标常见参考范围因方法与性别而异”），**绝不作为判定超标的标准**。是否超标一律读报告原文。
4. **跨报告参考区间变化必须显式标注。** 同一指标两张报告区间不同（换医院、换方法、换试剂），图表在该时间点打标记，并禁止把“区间变化”误读为“病情变化”。
5. **用户表参考值不得作为默认参考区间。** 附录 A 的参考值为用户整理值，其中 ALT/AST 采用的是**含 P5P** 的区间，而 WS/T 404.1 注明我国绝大多数实验室使用**不含 P5P** 试剂——直接套用会系统性误判（见 §9 TBD-16）。
