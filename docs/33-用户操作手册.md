# 33 用户操作手册

> 面向使用者（本人或代管家人）的操作说明。本手册只描述当前已实现的界面与操作；凡标注“计划中”的内容尚未上线，不要当作可用功能。
> 设计与规范见 docs/32-UI原型与设计规范.md，更早的草案见 docs/25-用户操作指南草案.md。

## 0. 先说清楚几件事

- HealthTrace 用来**整理和查看检验报告**，帮你把纸质报告、拍照、PDF 收在一处，并看到同一个指标随时间的变化。
- 它**不做诊断，不给用药或治疗建议**。图里的线只是把你自己的数据画出来。对结果有疑问，请找医生，不要照着图自行调整治疗。
- 一个账号管理**一位**患者的档案。“本人 / 子女 / 配偶 / 其他家人”只影响称呼，不增加权限。多档案切换属于计划中的能力。
- 报告原图和识别出的文字都只在你自己的账号里可见。退出登录后，页面不保留敏感缩略图。

---

## 1. 注册与登录

### 1.1 注册
1. 打开首页，点“注册”。
2. 填写**邀请码、邮箱、密码**，阅读并勾选必要告知后提交。
3. 系统会向这个邮箱发一封验证邮件。

### 1.2 验证邮箱
1. 打开邮件里的链接，页面会显示验证结果。
2. 如果链接过期，回到验证页点“重新发送”。
3. **邮箱未验证时，上传识别等写入操作会被拒绝**，页面顶部会有一条提示。先完成验证再继续。

### 1.3 登录与找回
- 用注册邮箱和密码登录。
- 忘记密码时走“忘记密码”，重置链接发到已验证的邮箱。
- 登录状态保存在浏览器的会话 Cookie 里；刷新页面不需要重新登录，手动“退出登录”后需要重新登录。退出登录的入口在**“我的”**页面底部。

---

## 2. 建立档案

第一次登录后，系统会直接带你到建档页，不建档无法使用其他页面（设置页例外，便于随时注销账号）。

1. 填**昵称**：显示在首页问候语里，建议用家人能认出的称呼，例如“妈妈”“张大爷”。
2. 选**关系**：本人 / 子女 / 配偶 / 其他家人。
3. 阅读并确认**授权声明**：如果你是代管者，这一步记录“你获得本人明确授权”的事实与时间。
4. 提交后进入首页。

档案建立后，再访问建档页会自动回到首页。

---

## 3. 四个页面分别做什么

登录后底部（手机）或左侧（电脑）始终有四个入口：

| 入口 | 作用 |
|---|---|
| **首页** | 问候、待处理报告、你关注的指标卡片、最近就诊 |
| **档案** | 全部报告的列表，按“检验报告 / 影像报告”分类筛选，上传入口 |
| **时间线** | 按日期倒序把就诊和报告合在一条轴上：某天去了哪家医院、做了什么检查、拿到哪份报告 |
| **我的** | 账号信息、关注指标管理、回收站、设置与隐私、退出登录 |

二级页面（趋势、报告对比、就诊、回收站、设置）会继续高亮它所属的那个入口，并在页面顶部提供返回链接。

## 4. 上传报告

点任意页面的**“＋ 上传报告”**（手机为右下角悬浮按钮）进入上传页。上传页分两类，请按手里的报告选择。

### 4.1 检验报告（有一项项数值的，如血常规、肝功能）

适用于“项目 / 结果 / 单位 / 参考范围”这种表格式报告。

1. 选“上传检验报告”。
2. **选择文件**：可以拍照、从相册选，或选 PDF。一份报告最多 20 个文件，可拖动调整页序（第 1 页是封面）。
3. 填**检查日期**：报告上的检查日，不是今天的上传日。不能晚于今天。
4. 如果同一张图之前上传过，页面会提示重复，你可以选择仍然保留或取消。
5. 决定是否**同意第三方 OCR 识别**：
   - 同意：系统把图片交给识别服务提取项目和数值，再由你核对。
   - 不同意：不调用任何外部服务，你可以手动录入数值。
6. 提交后报告进入“待处理”，识别完成会变成“待确认”。

### 4.2 影像报告（没有数值、只有结论的，如超声、X 光）

适用于腹部彩超、胸片这类报告——它们通常只有一段文字结论，没有可画成曲线的数值。

1. 选“上传影像报告”。
2. **填标题**：写得具体一点，例如“腹部彩超”“胸部正位片”。标题是以后在列表里找到它的主要线索。
3. 填**检查日期**和**医院**。
4. 上传**图片或 PDF**。
5. 填**“结论”**：把报告上的诊断结论抄进来，或留空交给系统识别。
   - 如果你同意 OCR，系统会尝试从图里提取诊断文字，作为这份报告的摘要填进来，你可以再修改。
   - 识别失败不影响保存，手填结论同样有效。
6. 提交后这份报告直接进入档案列表，**不需要逐项核对**，因为它没有指标项。

> 影像报告不会出现在趋势图里（没有数值可画），但会出现在档案列表、时间线，并且可以关联到就诊记录。

---

## 5. 核对报告（只有检验报告需要）

识别完成后，报告状态是“待确认”。首页“待处理”里点进去即可核对。

1. 左边是**原图**，右边是**识别结果**，逐项比对。
2. 每一项检查**名称、数值、单位、参考范围**是否和原图一致，不一致就直接改。
3. 识别把握不大的项会有提示，优先看这些。
4. 图片可以放大，方便看清小字。
5. 全部确认无误后点“保存正式报告”。保存后这份报告才算**已确认**，数值才会进入趋势图。
6. 没时间弄完可以“稍后继续”，它会留在待处理里。

> 注意区分三种状态：**已上传**（文件进来了）、**待确认**（识别完了但你还没核对）、**已确认**（你核对并保存了）。识别成功不等于保存成功。

### 5.1 改已确认的报告
已确认的报告仍可修改某一项数值。修改会留下历史记录：谁、什么时候、从什么改成什么，可在该项的“修改历史”里查看。

## 6. 看趋势

1. 先在**首页**或指标搜索里**关注**你关心的指标（例如“血红蛋白”）。关注后它会以卡片形式出现在首页。
2. 点卡片进入**趋势详情**。
3. 可以切换时间范围，点图上的点看那次的具体数值和来源报告。
4. 图右上可切换成**表格**，列出日期、数值、单位、参考范围——不方便看图时用这个。
5. 图下方有一段自动生成的文字描述，它只陈述数据本身（例如“最近 3 次在参考范围内”），**不会说“好转”或“恶化”**。

关于指标合并的几条规则，遇到提示时会用到：
- 同一档案里**同名同单位**的指标自动合并。
- **名称不同但单位相同**时，系统会给出合并依据和合并前后预览，由你决定合并或暂不合并；合并可以一键撤销。
- **同名但单位不同**不会自动合并，也不做换算，会提示风险并保持分开展示。
- 不同档案之间永不合并。

关注指标的增删和排序在**“我的” → 关注指标管理**里。

## 7. 就诊记录与报告绑定

“一次就诊”对应你去医院的那一天。把报告挂到就诊下面，以后回看就知道“这天去协和做了这几项检查”。

### 7.1 记录一次就诊
1. 进**时间线 → 就诊记录**，点“添加就诊”。
2. 填**就诊日期、医院**，可选填**科室**和**备注**。
3. 保存。

### 7.2 给就诊关联报告
1. 打开就诊详情，找到**“关联报告”**区块。
2. 点“添加报告”，从这个档案已有的报告里选。
3. 关联后这里会列出报告标题和各自的检查日期（检查日可能和就诊日不同，属正常）。
4. 点报告旁的“移除”解除关联。移除只是解除关系，**不会删除报告本身**。

### 7.3 从报告看就诊
打开报告详情，页面会列出**这份报告关联的所有就诊记录**，点进去可以跳到那次就诊。一份报告可以关联多次就诊（例如复查时带去）。

### 7.4 时间线怎么读
时间线把就诊和报告按日期**倒序合在一起**：同一天先显示就诊，再显示那天的报告。这样一屏就能看出“哪天去了医院、拿到了什么”。

## 8. 删除与回收站

两种删除，区别很重要：

| 操作 | 效果 | 位置 |
|---|---|---|
| **从列表移除** | 报告不在档案列表里显示，数据仍然保留，可以还原 | 报告详情 |
| **彻底删除** | 报告、原图、识别数据一并删除，**不可恢复** | 回收站 |

- 被移除的报告去**“我的” → 回收站**，在那里可以**还原**或**彻底删除**。
- 彻底删除前会要求你再确认一次，确认文案会说明不可恢复。
- 删除行为会被记录在审计日志里（谁、什么时候删了什么）。

---

## 9. 设置与隐私

**“我的” → 设置与隐私**里可以：
- 查看邮箱**验证状态**，重新发送验证邮件。
- 阅读**隐私与 OCR 说明**：数据存在哪、识别时会把什么交给谁。
- **注销账号**：删除账号及其全部数据，不可恢复。未建档的账号同样可以注销。
- 了解**人工撤回渠道**：需要人工处理的权利请求（导出、更正等）走这里。

## 10. 遇到问题

| 现象 | 处理 |
|---|---|
| 提示“邮箱尚未验证” | 去设置页重发验证邮件，点邮件里的链接 |
| 上传一直不动 | 手机浏览器切到后台可能中断上传，回到页面重试；系统不承诺后台续传 |
| 识别结果错得多 | 直接在核对页改，或改用手动录入；识别失败不影响你保存报告 |
| 找不到某份报告 | 看“档案”页的分类筛选是否限制了类型；再确认是否被“从列表移除”，去回收站找 |
| 趋势图里没有某次数值 | 该报告可能还停在“待确认”，核对保存后才会进图；影像报告没有数值，不会进图 |
| 点不到按钮 / 字太小 | 浏览器可放大到 200%，布局不会错乱 |
